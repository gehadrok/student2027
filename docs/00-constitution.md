# 00 - دستور المشروع (Constitution)
## نظام إدارة مدرسة السلام

هذا الملف يمثل **القواعد الثابتة التي لا يجوز مخالفتها** أثناء التنفيذ، بغض النظر عن نموذج الذكاء الاصطناعي المستخدم في الكتابة. أي نموذج (رخيص أو مكلف) يجب أن يقرأ هذا الملف قبل تنفيذ أي مهمة من ملف `03-tasks.md`.

---

## 1. القواعد التقنية الثابتة (Non-Negotiable)

1. **لا أطر عمل واجهة خارجية.** ممنوع استخدام React / Vue / Angular / jQuery. فقط `HTML5 + CSS3 + JavaScript (ES6 Modules)` خام.
2. **قاعدة البيانات:** RealmDB فقط (عبر `Realm Web SDK` أو `realm-js` حسب البيئة المستخدمة). لا localStorage كقاعدة بيانات أساسية (يجوز فقط لتخزين جلسة الدخول المؤقتة/التوكن).
3. **بنية الوحدات (Modules):** كل ملف JS يمثل وحدة واحدة مسؤولة عن شيء واحد فقط (Single Responsibility). ممنوع كتابة كل المنطق في ملف واحد ضخم.
4. **التسمية:**
   - أسماء الملفات: `kebab-case.js` (مثل `student-service.js`).
   - أسماء الدوال والمتغيرات: `camelCase`.
   - أسماء الكلاسات (Classes/Models): `PascalCase`.
   - أسماء كائنات RealmDB (Schema Names): `PascalCase` مطابقة لاسم الكيان (مثل `Student`, `Grade`).
5. **اللغة:** الواجهة بالكامل عربي (`dir="rtl"`, `lang="ar"`). التعليقات البرمجية بالإنجليزية للوضوح التقني، والنصوص الظاهرة للمستخدم بالعربية.
6. **الألوان (يجب أن تكون CSS Variables في ملف واحد `variables.css` ولا يجوز كتابة Hex Codes مباشرة في أي مكان آخر):**
   ```css
   --color-primary-blue: #1E3A8A;   /* أزرق أساسي - الهوية */
   --color-primary-blue-light: #3B82F6;
   --color-success-green: #16A34A;  /* أخضر - نجاح/حاضر/مدفوع */
   --color-danger-red: #DC2626;     /* أحمر - تنبيه/غياب/متأخر */
   --color-bg: #F5F7FA;
   --color-surface: #FFFFFF;
   --color-text-primary: #1F2937;
   --color-text-secondary: #6B7280;
   --color-border: #E5E7EB;
   ```
7. **الخط:** `Tajawal` أو `Cairo` عبر Google Fonts، مع fallback إلى `sans-serif`.
8. **لا مكتبات خارجية إلا عبر CDN وبموافقة صريحة** مذكورة في `02-plan.md` (مسموح فقط بـ: Chart.js للرسوم البيانية، jsPDF لتوليد PDF، Realm SDK). أي مكتبة أخرى ممنوعة.
9. **كل شاشة (Page) لها:**
   - ملف HTML مستقل داخل `/pages`
   - ملف JS مستقل مرتبط بها داخل `/scripts/pages`
   - لا تكرار كود بين الصفحات؛ أي منطق متكرر ينقل إلى `/scripts/shared` أو `/scripts/components`.
10. **الأمان:** كل عملية كتابة/قراءة في RealmDB تمر عبر طبقة `services` فقط. ممنوع استدعاء RealmDB مباشرة من كود الصفحة (UI Layer).

---

## 2. قواعد تنفيذ المهام (لأي نموذج ذكاء اصطناعي منفذ)

- كل مهمة في `03-tasks.md` لها معرف فريد (`T001`, `T002`, ...) ويجب تنفيذها **بترتيبها** لأن كل مهمة تعتمد على سابقتها.
- **لا تتجاوز حدود المهمة.** إذا كانت المهمة "إنشاء ملف X فقط"، لا يجوز إنشاء ملفات إضافية غير مذكورة.
- **لا تخترع أسماء حقول أو دوال جديدة.** استخدم فقط الأسماء المحددة في `02-plan.md` (قسم نموذج البيانات وقسم الدوال).
- بعد كل مهمة، يجب التحقق من "معايير القبول" (Acceptance Criteria) المذكورة في المهمة نفسها قبل الانتقال للتالية.
- إذا واجه النموذج غموضًا، عليه اتباع القيم الافتراضية المذكورة في هذا الملف بدلاً من الارتجال.
- ممنوع حذف أو تعديل ملفات خارج نطاق المهمة الحالية.
- كل مهمة يجب أن تنتج كودًا **قابلاً للتشغيل فورًا** دون أخطاء syntax، حتى لو كانت الوظيفة جزئية.

---

## 3. تعريف "تم" (Definition of Done) لأي مهمة

مهمة تُعتبر مكتملة فقط إذا:
- [ ] الملفات المذكورة في المهمة تم إنشاؤها/تعديلها بالضبط كما هو مطلوب.
- [ ] لا يوجد أي استدعاء لمكتبة أو إطار عمل غير مصرح به.
- [ ] الكود يتبع قواعد التسمية في القسم 1.
- [ ] تم اختبار السيناريو الأساسي يدويًا (فتح الصفحة في المتصفح دون أخطاء Console).
- [ ] لا يوجد نص عربي مكسور (Encoding) أو اتجاه خاطئ (LTR بدل RTL).

## 4. هيكل المشروع الجذري (مرجعي - التفاصيل الكاملة في 02-plan.md)

```
al-salam-school/
├── index.html                # شاشة تسجيل الدخول (نقطة البداية)
├── pages/                    # كل شاشة HTML مستقلة
├── scripts/
│   ├── db/                   # طبقة RealmDB (schemas + connection)
│   ├── services/             # منطق الأعمال (CRUD لكل كيان)
│   ├── shared/                # أدوات مشتركة (auth guard, router, utils, notifications)
│   ├── components/           # مكوّنات UI قابلة لإعادة الاستخدام (sidebar, navbar, modal, table)
│   └── pages/                # منطق كل صفحة على حدة
├── styles/
│   ├── variables.css
│   ├── base.css
│   └── components/
├── assets/
│   ├── icons/
│   └── logo/
└── README.md
```
