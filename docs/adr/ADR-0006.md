# ADR-0006: TypeScript and ES6 Modules End-to-End

**Status:** Accepted
**Date:** 2026-08-01

## Context

The existing platform is implemented in TypeScript with ES6 modules across `src/core/`, `src/modules/`, and `src/lib/`. Repository interfaces, infrastructure contracts, and composition root are all TypeScript. The Constitution restricts external frameworks and libraries.

## Decision

Adopt **TypeScript end-to-end with ES6 modules** as the implementation language and module system:

- Typed interfaces for commands, queries, DTOs, repositories, and snapshots.
- ES6 module imports/exports with folder-level `index.ts` barrels.
- Strict boundary enforcement through types (domain cannot depend on infrastructure).
- No unapproved external frameworks; additions require review and an ADR where material.

## Consequences

**Positive:**

- Compile-time boundary and contract safety.
- Consistent with existing core/module code.

**Negative:**

- Type overhead in early skeleton phases.

## Rationale

The platform is already TypeScript/ES6; this ADR records the existing decision so future domains follow the same language and module discipline (Student Domain Standard, Engineering Governance).
